# 水墨扁平留白重构海报

## Usage

- Use case: 适合把风景、建筑、旅行或人文摄影转绘成极简水墨插画海报，用于展览视觉、作品集封面、文化刊物或具有学术气质的编辑设计。
- Input requirements: 上传一张上半部分包含明确景物的原图，并提供【英文标题】与【英文描述短句】；如未提供文字，可根据画面主题生成简短、克制的英文文案。
- Expected result: 输出一张以米白哑光纸为底、留白充足的极简海报；原图上半部分景物被概括为柔和几何色块与淡墨笔触，底端居中排列两行英文文字。
- Notes: 必须沿用原图整体色彩调性与主要空间关系，但不追求照片级细节；删除琐碎纹理、杂物和复杂光影。文字仅保留标题与描述两行，不添加 Logo、边框、印章或其他装饰。

## Original Prompt

```text
独立的米色留白区域，置入水墨扁平重构插画。提取上半部分全部景物，将其解构为极简几何形态。运用分层平涂的柔和色块，结合毛笔淡墨的晕染笔触，彻底摒弃锐利硬边。严格复刻原图整体色彩调性，剔除所有细碎纹理、冗余杂物及复杂光影、仅保留纯粹的结构神韵。排版文字：画面最底端，底部居中排版。首行为优雅的衬线手写体英文标题，次行为字号更小的无衬印英文描述短句。整体质感：基于米白哑光特种纸底色，大面积留白理念。呈现干净高级且具有学术感的视觉效果，无任何多余装饰元素
```

## Full Prompt

```text
使用上传的原图创作一张极简水墨扁平重构海报。

【内容提取】
- 观察并提取原图上半部分的全部主要景物，包括具有辨识度的地貌、建筑、植物、人物或其他核心对象。
- 保留各主体之间的基本位置、比例、层次与空间关系，确保重构后仍能辨认原图的场景神韵。
- 将所有景物解构并概括为简洁、克制的几何形态，只保留最具代表性的轮廓、体块与结构节奏。
- 删除细碎纹理、冗余杂物、偶然性背景元素和不影响主题识别的局部细节。

【插画语言】
- 将提取出的景物置入一块独立、完整的米色留白区域，形成水墨与扁平设计融合的重构插画。
- 使用分层平涂的柔和色块组织前景、中景与远景，色块边缘自然、松弛、略带手工感。
- 在平涂色块之间融入毛笔淡墨的晕染、渗化与轻柔笔触，使画面具有含蓄的东方水墨气息。
- 彻底摒弃锐利硬边、机械描边、厚重黑线和高对比切割；轮廓应柔和、朦胧、自然过渡。
- 不使用写实渲染，不刻画复杂材质，不制造强烈体积光、镜面高光、戏剧化阴影或繁复明暗关系。

【色彩】
- 严格继承原图的整体色彩调性，从原图中提取主色、辅助色与少量强调色。
- 在不改变原图冷暖倾向和色彩关系的前提下，适度降低饱和度与对比度，使色彩呈现柔和、安静、哑光的印刷质感。
- 不引入与原图无关的鲜艳颜色，不使用霓虹色、艳丽渐变或强烈撞色。

【版式与留白】
- 以米白色、无反光的哑光特种纸作为完整画面底色。
- 采用大面积留白构图，插画区域与画布边缘、底部文字之间均保持宽裕而均衡的呼吸空间。
- 画面重心稳定、疏朗、克制，不使用边框、色带、贴纸、拼贴、印章、图标或任何额外装饰。

【底部文字】
- 所有文字位于画面最底端并整体居中，与插画保持清晰间隔。
- 第一行写【英文标题】，使用优雅、纤细、带手写气质的衬线字体，作为主标题。
- 第二行写【英文描述短句】，使用字号更小、字重较轻的无衬线字体，保持简短、克制，并与标题留出精致的行距。
- 除这两行英文外，不出现其他文字、数字、Logo、水印或符号。

【整体效果】
- 最终画面应干净、高级、安静且具有学术出版物与艺术研究档案般的视觉气质。
- 依靠纯粹的结构、柔和色块、淡墨笔触、纸张质感和大面积留白建立美感。
- 保留原场景的结构神韵和色彩记忆，同时避免照片感、商业广告感、卡通感、复杂装饰与过度设计。
```
