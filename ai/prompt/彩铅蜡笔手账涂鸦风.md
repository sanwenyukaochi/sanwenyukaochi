# 彩铅蜡笔手账涂鸦风图片转绘提示词记录

## 适用场景

用于将任意照片或插画转化为一种「彩铅 + 蜡笔 + 手账贴纸 + MS Paint 涂鸦」混合风格的视觉效果。

适合用于：

* 人像照片二创
* 游戏截图风格化
* 二次元萌系改图
* 可爱手账风图片创作
* 互联网 kawaii aesthetic 风格图像生成或重绘

整体风格关键词：
可爱、混乱、梦幻、少女感、游戏宅手账风、幼稚但有灵气、手绘失败感、乱涂鸦感。

## 完整提示词

```text
分析图片内容提取核心重点，不要遗漏主题特点，整体转化为「彩铅 + 蜡笔 + 手账贴纸 + MS Paint 涂鸦」混合风格。 

【整体风格】 
- 整体效果像是彩铅、蜡笔、手账贴纸与 MS Paint 涂鸦结合而成。 
- 画面要带有强烈的手绘感、拼贴感和随手乱画的可爱感。 
- 风格故意幼稚，但要很有灵气，不要精致，不要高级。 

【线条与质感】 
- 使用粗糙线条、抖动边缘、不稳定描边。 
- 加入不均匀上色、纸张纹理、彩铅叠色、蜡笔颗粒感。 
- 允许轻微涂出边界、叠色不均、笔触明显、边缘发抖等效果。 
- 保留“手绘失败感”和“乱涂鸦感”。 
- 不要干净线稿，不要流畅精修轮廓。 

【人物表现】 
- 如果画面中有人物，请将人物转化为 Q 版萌系二次元风格。 
- 人物要有大眼睛、夸张表情、可爱活泼的气质。 
- 整体更偏 chibi、萌系、灵动的表现方式。 
- 可以适度加入脸红、开心笑、星星眼等可爱情绪细节。 

【背景与装饰】 
- 背景加入大量 doodle 涂鸦元素。 
- 可加入：爱心、星星、糖果、笑脸云朵、小花、贴纸、游戏 UI 元素、乱涂乱画符号。 
- 装饰元素要丰富，营造手账拼贴与涂鸦本页面的感觉。 
- 画面整体可以热闹、可爱、杂乱，但要保持主题明确。 

【颜色要求】 
- 主色调以粉色、蓝色、紫色、黄色、薄荷色为主。 
- 色彩要甜美、梦幻、活泼，具有少女感和互联网 kawaii aesthetic 氛围。 
- 可以有彩铅叠色、蜡笔混色、轻微脏感和不均匀的上色效果。 

【氛围要求】 
- 整体氛围要可爱、混乱、梦幻、少女感。 
- 呈现出游戏宅手账风与互联网 kawaii aesthetic 的视觉气质。 
- 画面不要过于成熟，不要过于商业化，要像带有个人情绪和随手创作感的手绘作品。 

【负面要求】 
- 不要精致插画感。 
- 不要高级商业插画感。 
- 不要真实渲染。 
- 不要干净线稿。 
- 不要写实质感。 
- 不要做得太整洁、太规整、太高级。 

最终效果应像一张由彩铅、蜡笔、贴纸和涂鸦共同构成的可爱梦幻手账风画面，带有明显的手绘感、乱涂乱画感，以及幼稚但有灵气的视觉表现。
```
