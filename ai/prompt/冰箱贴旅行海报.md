# 固定模板冰箱贴旅行海报

## Usage

- Use case: 适合将不同城市或国家的旅行照片制作成视觉规格统一的系列海报。
- Input requirements: 上传一张旅行原图，并提供【城市名】和【国家名】；如有需要，可补充希望突出或避免使用的当地景观。
- Expected result: 输出一张 2:3 竖版旅行海报，上方为当地景观珐琅冰箱贴与地点文字，下方完整保留旅行原图。
- Notes: 系列制作时必须固定上下区域比例、冰箱贴尺寸、文字位置、字号和间距；除【城市名】与【国家名】外不要添加其他文字。

## Original Prompt

```text
按固定旅行海报模板制作：竖版 2:3，上半部分约45%，下半部分使用我的原图并保持人物、景观、构图和色调不变。上方采用中等明度的蓝紫/灰蓝哑光背景，居中放一个偏小的不规则冰箱贴，根据原图提取当地代表性景观，并在合适时融入原图人物。冰箱贴为精致珐琅质感，只保留轻微金属描边，不要太金属、太暗或太亮。下方文字只保留「城市名 + 国家名」，使用高级细衬线字体、宽字距，中间加入细线和小菱形装饰。整体保持 quiet luxury、高级旅行杂志感，并严格统一每张的比例、冰箱贴大小、文字位置和间距。
```

## Refined Prompt

```text
使用上传的旅行照片制作一张固定模板的系列旅行海报。

【输入信息】
- 城市名：【城市名】
- 国家名：【国家名】

【画布与版式】
- 使用 2:3 竖版画布。
- 上方设计区约占画面高度的 45%，下方照片区约占 55%。
- 严格保持系列模板一致：上下区域比例、冰箱贴尺寸与位置、文字基线、字号、字距、装饰线长度以及各元素间距均不得随照片改变。

【下方照片区】
- 直接使用上传的原图。
- 保持原图中的人物、景观、构图、光线和整体色调不变。
- 不要重绘人物，不要改变五官、姿态、服装或人物数量；不要替换、增加或删除景观元素。
- 不要对照片使用额外风格化滤镜，也不要为了匹配上方设计而改变原图色彩。

【上方设计区】
- 使用中等明度、低饱和度的蓝紫色或灰蓝色哑光纯色背景，整体克制、柔和，不要过暗或过亮。
- 在上方区域居中放置一个偏小的不规则造型冰箱贴，并在周围保留充足留白。
- 根据原图和旅行地点提取最有代表性的当地景观，将其概括成精致的珐琅冰箱贴图案。
- 原图人物适合成为地点记忆的一部分时，可将人物自然融入冰箱贴；不适合时只使用代表性景观，不要强行加入。
- 冰箱贴采用细腻、精致的彩色珐琅质感，仅保留纤细、轻微的金属描边。避免强烈金属反光、厚重金边、阴暗材质或刺眼高光。

【地点文字】
- 文字内容只保留【城市名】与【国家名】，不要添加日期、口号、说明文字、Logo 或其他字符。
- 使用高级、克制的细衬线字体和较宽字距，居中排版。
- 在城市名与国家名之间加入一条纤细水平线和一个小菱形装饰。
- 文字与装饰应清晰但不过分抢眼，并与冰箱贴保持稳定、舒适的间距。

【整体风格】
- 呈现 quiet luxury、高级旅行杂志和精品酒店画册般的视觉气质。
- 画面简洁、安静、克制、精致，依靠比例、留白、字体和材质体现高级感。
- 避免旅游宣传单风格、复古明信片风格、复杂拼贴、夸张装饰、艳丽渐变和拥挤排版。

最终输出必须像同一旅行海报系列中的一张：模板结构高度统一，只允许地点、冰箱贴图案和下方原图随每次输入变化。
```

## Quick Version

```text
将上传的旅行照片制作成固定模板的 2:3 竖版系列海报。上方约占 45%，使用中等明度、低饱和度的蓝紫或灰蓝哑光背景；居中放置一个偏小的不规则珐琅冰箱贴，根据原图与地点提取代表性景观，合适时融入原图人物。冰箱贴只使用纤细、轻微的金属描边，避免过强金属感、厚重金边、暗沉材质和刺眼高光。

下方约占 55%，直接使用原图，保持人物、景观、构图、光线和色调不变，不要重绘、增删元素或添加滤镜。文字只保留【城市名】与【国家名】，使用高级细衬线字体、宽字距和居中排版，两者之间加入细线与小菱形。整体呈现 quiet luxury 和高级旅行杂志感。系列中的每张海报必须严格统一区域比例、冰箱贴大小与位置、文字位置、字号和间距。
```
